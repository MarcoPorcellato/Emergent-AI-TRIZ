This directory stores the proposed adaptive protocol for A0.

The run remains exploratory and does not freeze into a final result.

Required contract points:

- empirical execution,
- exploratory scientific status,
- evidence_eligible is false,
- expert_validated is false,
- claim_ids is empty,
- exact model and tokenizer revision `EleutherAI/pythia-70m-deduped` @
  `e93a9faa9c77e5d09219f6c868bfc7a1bd65593c`,
- six neutral domains,
- operator proxy families `segmentation_like` and `inversion_like`,
- deterministic predeclared calibration rule,
- family-grouped calibration and sealed partitions,
- preregistered layers `[0, 2, 4, 6]`,
- fixed views and token sites,
- fail-closed outcomes only in `positive`, `null`, `failed`, and `non_interpretable`.

Protocol runtime explicitly requires `requires_interactive_model_server = false`.

No claim language is introduced in this directory.
