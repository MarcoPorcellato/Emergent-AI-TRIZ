# Annotation ontology v1.2 cognitive pilot

This protocol is ready for three independent TRIZ experts to review six
sanitized cases. It is a guide-usability gate, not a hypothesis experiment.

The experts must use separate rater identifiers and output files. Generator
targets, provenance, and related-case identities remain hidden. Each expert
should answer every question in protocol.json while using the v1.2 workbench.

The pilot is complete only after all three experts have reviewed all six cases,
the ambiguous guide language has been synthesized qualitatively, and an
explicit keep-or-amend decision has been recorded. Until then, ontology v1.2
remains in development and Wave 2 human collection must not begin.

No result is included in this directory because no independent expert session
has yet occurred. Empty or synthetic responses must never be substituted for
human cognitive-pilot evidence.
