# Lab 06 — causal intervention readiness

This document is a no-model readiness contract. It does not authorize model
loading, activation extraction, steering, ablation, sealed-target access, or
causal claims. A material run requires a separate frozen dossier and explicit
operator approval.

## Preconditions

All of the following must be terminally verified before a dossier can request
execution:

1. H1 is closed with three independent TRIZ experts, raw ratings, agreement,
   abstention, adjudication, and keep/amend receipts.
2. Canonical labels are frozen separately from generator intent and source-
   exposed records.
3. Lab 05 D1–D8 pass on an out-of-sample held-out-domain direction.
4. The operator is selected by frozen expert/data rules, not by inspecting the
   causal or sealed outcome.
5. The intervention parameters, target behavior, controls, sample size, seed,
   stopping rule, multiplicity, and capability tasks are frozen.
6. The exact model, code, dataset, runtime, resource budget, and external dense
   asset policy are hash-bound.

## Required intervention arms

- positive steering along the frozen operator direction;
- opposite-sign steering;
- ablation or projection removal;
- at least three preregistered dose levels;
- norm-matched random directions;
- unrelated-label directions;
- no-intervention baseline;
- fluency and capability-preservation tasks.

The primary outcome is held-out-domain operator behavior. Recognition,
source-exposed retrieval, and generic helpfulness are secondary and cannot
rescue a failed causal primary.

## Terminal rules

The package must publish `positive`, `null`, `failed`, or
`non_interpretable`. A positive package may claim only a causal effect of the
frozen representation intervention on the frozen automated proxy. It may not
claim TRIZ rediscovery, inventiveness, expert competence, or general reasoning.

Any missing label, control, receipt, capability check, or integrity hash is
`non_interpretable`. Any model or target access consumes the one authorized run;
retry, tuning, model substitution, and protocol changes require a new dossier.

## Required publication artifacts

- execution and resource receipt;
- intervention parameter and direction receipt;
- immutable activation/behavior index;
- statistical result and confidence intervals;
- capability-preservation result;
- recovery observation;
- external dense-asset locator and SHA-256;
- publication manifest and fresh-clone verifier evidence;
- report of limitations and every terminal outcome.

## Cost and safety boundary

Synthetic adapters, fixed vectors, mutation tests, and statistical calibration
must pass before any material CCP run. The run is local-only CPU float32,
network-disabled, generation-disabled unless explicitly required by the frozen
protocol, and admitted only when CCP reports `Admit`, inactive admission, and
an empty queue. No target is opened before the declared analysis boundary.
